Geospatial QA/QC Workbench

QA/QC means checking a delivered dataset against its specification before anyone uses it. Pick the product you are checking. Each step shows what to check, how to do it in ArcGIS Pro, QGIS and code, the ISO 19157-1 quality element it tests, and the errors it catches.

RMSE, CE90 and LE90 from check points

One point per line: dx, dy or dx, dy, dz in metres (dataset minus check point). Export them from ArcGIS Pro Extract Values to Points or QGIS Sample raster values and paste here.

CE90 ≈ 1.5175 × RMSEr, LE90 ≈ 1.6449 × RMSEz, assuming normal errors with no bias and similar RMSE in x and y. Use at least 20 independent, well-distributed check points.

Land cover confusion matrix

Rows: class on the map. Columns: class in the reference (what the checker saw). Enter the number of sample points in each cell.

User's accuracy: of the points mapped as a class, how many really are that class (reliability for map users). Producer's accuracy: of the real class, how much the map captured. In ArcGIS Pro, Compute Confusion Matrix produces the same table; in QGIS, the AcATaMa plugin.

Every check in the workflow tests one of the six ISO 19157-1 quality elements. Open a sub-element for a plain definition and an example from the four products.
